# pi5-ground-station-backup

本项目共有三版地面站，灵感全部来自于全国大学生电子设计大赛无人机题
gcs_2026是2026电赛陆空协同无人机的地面站，该地面站已经完成电赛要求的所有功能，可以和无人机小车三端通信。
gcs_pi5是2025年电赛野生动物巡查系统的地面站，该地面站主要是路径规划然后将无人机所需要的参数（期望速度，期望位置等）发送给无人机。
